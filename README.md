# 引大灌区调查数据采集系统

用于引大入秦灌区现状调查数据的本地化录入、管理、查询与 Excel 成果导出。

## 当前版本

**V0.2.0 开发版**

当前已完成附表2.2（水闸工程状况调查表）的完整业务闭环，包括：

- 项目与调查批次
- 组织机构与渠系基础资料
- 工程业务编号
- 工程台账
- 调查草稿保存与继续编辑
- 调查完成与完成记录修改
- A/B/C/D 分项评价
- 重复调查控制
- 调查记录删除
- 未保存修改保护
- 列表筛选与统计
- Excel 数据汇总导出
- 附表2.2原表格式 Excel 导出
- SQLite 自动备份

后续继续扩展其它调查附表及查询、成果管理等功能。

## 技术栈

- Python
- PySide6
- SQLite
- openpyxl
