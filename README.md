## 工程调查框架

附表2.1～2.6的录入层已经统一采用声明式工程调查框架：

```text
EngineeringFormDefinition
        ↓
EngineeringFormRegistry
        ↓
GenericEngineeringSurveyPage
        ↓
generic persistence
        ↓
point / range common DB API
```

每张工程调查表主要保留自身的：

- 正式字段定义
- 页面分区与字段布局
- 工程位置类型
- A/B/C/D评价标准
- 必要的列表表现差异
- 正式Excel成果差异

相同业务语义优先使用公共实现，不再为每张附表复制一套录入页、CRUD和完成逻辑。

## 当前开发方向

下一阶段优先继续收敛附表2系列的公共展示与导出能力，包括：
