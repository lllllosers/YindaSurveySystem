## 首页统计口径

当前首页“已录完成率”定义为：

`已完成记录数 /（已完成记录数 + 草稿记录数）`

数据库目前没有权威的“某处 / 某管理单位应调查工程总量”计划基准，因此该比例不得表述为辖区最终工作量完成率。若后续甲方需要真正的计划完成率，应增加独立的计划任务量 / 应调查工程量基准。
