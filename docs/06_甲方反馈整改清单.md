## 首页统计口径

当前首页“已录记录完成率”定义为：

```text
录入完成记录数 / 已录记录数
```

数据库目前没有权威的“某处 / 某管理单位应调查工程总量”计划基准，因此该比例不得表述为辖区最终工作量完成率。

任务分发历史中的“已有成果返回”同样只表示已经有调查记录返回总库，不表示整个任务已经全部完成。
