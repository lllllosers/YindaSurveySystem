## 3. 人工生产验收

自动测试全部通过后，使用程序界面进行一次人工模拟。

### A. 总库准备

1. 新建或选择一个测试项目和调查批次。
2. 确认基础资料、管理单位、渠系和分管范围完整。
3. 在“任务分发”中分别为两个不同管理单位生成任务包。
4. 检查“已分发任务”出现两条记录，初始均为“待回收”。

### B. 两个独立调查端

1. 使用两个独立测试数据库分别接收两个任务包。
2. 每个调查端至少完成一条附表2工程调查记录。
3. 分别生成调查成果包。

### C. 分阶段回收

1. 总库先接收第一个成果包。
2. 检查：
   - 对应任务变为“已有成果返回”；
   - 另一任务仍为“待回收”；
   - 成果接收历史只有一个成果包；
   - 工程台账、数据查询、首页统计只增加第一个单位的数据。
3. 再接收第二个成果包。
4. 检查：
   - 两个任务均显示“已有成果返回”；
   - 成果接收历史有两个成果包；
   - 工程台账、数据查询、首页统计均包含两个单位的数据。

### D. 重复与异常操作

1. 再次选择已经导入过的同一成果包。
2. 系统不得重复生成工程对象、调查记录、分项评价或影像。
3. 用错误项目/批次或被篡改的测试成果包执行预检，应被阻止。
4. 检查导入前备份文件能够正常生成。

## 4. V1.0 发布判定

满足以下条件后，Stage 7 可判定完成：

- Stage 7.1～7.4 针对性测试全部通过；
- 数据交换相关回归测试全部通过；
- `run_tests.bat` 全量通过；
- 上述人工生产验收 A～D 无阻断性问题；
- 工程台账、数据查询、首页、任务分发历史、成果接收历史对同一批次数据的统计口径一致。

本矩阵不把“已有成果返回”等同于“任务整体完成”。当前系统没有任务级“应调查记录总量”的权威基准，因此 V1.0 仅展示已回收记录数量和是否已有成果返回。
