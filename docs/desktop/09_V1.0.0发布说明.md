# V1.0.0 发布说明

## 版本信息

- 产品名称：引大入秦工程现状调查采集系统
- 版本：V1.0.0
- 阶段：正式版
- 发布收口日期：2026-09-19

## 正式业务范围

V1.0.0 正式支持附表2.1～2.14工程现状调查，包括调查录入、分项评价、工程台账、数据查询、正式原表导出、任务分发/接收以及成果提交/接收。

附表1.1～1.15当前保留预留入口和底层扩展能力，但不启用软件化录入。

## 主要能力

- PySide6 + SQLite 单机本地化运行；
- 项目与调查批次管理；
- 组织机构、物理渠系与分管范围管理；
- 附表2.1～2.14完整调查生命周期；
- 工程台账、历次调查、数据查询和 Excel 导出；
- `.ydtask` 调查任务包；
- 冻结任务工作区和分管范围；
- `.ydresult` V2 调查成果包；
- 上级端成果预检、自动备份、事务化导入和重复导入保护；
- `source_task_uid + source_management_scope_uid` 来源追踪；
- 任务分发历史与成果接收历史；
- 多管理单位成果顺序回收和总库归并。

## V1.0 验收

## 已知边界

1. 首页“已录记录完成率”只表示已录数据中的录入完成比例，不表示辖区最终工作量完成率。
2. “已有成果返回”只表示该任务已有调查记录返回，不表示任务整体完成。
3. 附表1系列当前未启用桌面软件录入。
4. V1.0.0 为本地桌面单机业务系统，不包含 Web Center / Web Hybrid 实验能力。
5. 正式运行数据保存在本地 `local_data` 中；正式发布包不得预置开发数据库。

## 数据安全

正式成果导入前系统自动创建数据库备份，并采用事务化导入。任务和成果跨电脑交换均使用稳定 UID 与冻结历史事实核验来源。
