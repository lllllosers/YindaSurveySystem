# V1.1.0 发布说明

## 版本信息

- 产品名称：引大入秦工程现状调查采集系统
- 版本：V1.1.0
- 阶段：正式版
- 收口日期：2026-09-20
- 升级基线：V1.0.2

## 本次版本重点

V1.1.0 正式实现桌面端原生三级任务与成果链：

```text
中心
  ↓ T1：处级父任务
基层处
  ├─ T2：所A子任务 → 所A成果
  └─ T3：所B子任务 → 所B成果
             ↓
          基层处汇总
             ↓ submission_task_uid = T1
            中心
```

V1.0.2 中用于三级协作的“复制中心 local_data 给处”的中继方案不再是标准工作流。

## 任务谱系

`.ydtask` 当前写出 schema 为 V3，并保存：

```text
task_uid
parent_task_uid
root_task_uid
task_depth
```

V2 任务包继续支持兼容读取并归一化为根任务；旧 V1 测试格式不保留生产兼容路径。

中心可直接把任务目标设为基层处。处级父任务不建立虚构的处级 `CanalManagementScope`，而是冻结选中的下属水管所 scope 集合。

基层处只能从父任务冻结范围派生子任务，后端强制：

```text
child scopes ⊆ parent frozen scopes
```

同时校验目标水管所为当前处直接下属、scope owner 与目标水管所一致。

## 成果来源与提交责任分离

调查记录继续使用：

```text
source_task_uid
+
source_management_scope_uid
```

表示真实调查来源。

V1.1.0 新增成果 envelope 字段：

```text
submission_task_uid
```

表示“当前成果是针对哪个上级任务提交”。

例如处汇总所A、所B成果后：

```text
submission_task_uid = T1

record A source_task_uid = T2
record B source_task_uid = T3
```

中心只需要验证自己实际下发的 T1，不需要伪造 T2/T3 issued history，也不会把记录真实来源改写为 T1。

## 处级自动汇总

处端当前 workspace 为处级父任务时，系统自动：

- 读取父任务冻结 scope；
- 选取当前项目/批次中合法的 completed 调查记录；
- 校验记录来源任务是否为当前父任务或其直接合法子任务；
- 校验子任务目标水管所；
- 校验 scope owner；
- 校验物理渠系；
- 自动把父任务 UID 写入 `submission_task_uid`。

处级 `.ydresult` 汇总不受上方普通水管所/渠系/表单筛选误切割，避免将一个父任务成果静默拆碎。

## UI 工作流

### 中心端任务分发

中心端保留原中心→水管所直接下发能力，同时新增“整个基层处”目标。

### 基层处任务分发

处端接收父任务后：

- 基层处固定为当前处；
- 只能选择父任务范围中的下属水管所；
- 每个所仅显示自己在父任务中被冻结的 scope；
- 不能超出父任务范围再次分配。

### 水管所端

水管所是执行端，不能继续向下分发任务。

### 成果提交

- 所端自动按当前 child task 提交；
- 处端自动进入父任务汇总模式；
- 处级汇总界面显示待汇总记录数、来源子任务数、水管所数和分管范围数。

## 自动化与人工验收

V1.1.0 已完成：

- Stage 4.1～4.5C 全部专项测试；
- 四套独立 `local_data` 的中心—处—两个水管所—处—中心自动往返；
- 全量自动化回归；
- 实际 UI 人工生产验收。

人工验收确认：

1. 中心生成 T1 处级父任务；
2. 处接收 T1 后分别生成 T2/T3；
3. 两个所使用独立数据库接收任务并录入；
4. 两个所分别生成成果回处；
5. 处依次预检、导入并保持当前 T1 workspace；
6. 处自动汇总 T2/T3 记录生成针对 T1 的成果；
7. 中心在没有 T2/T3 issued history 的情况下按 T1 验收通过；
8. 中心最终记录仍保留 T2/T3 的 `source_task_uid`；
9. 直接把 T2 所级成果交给中心时仍会因无授权而拒绝；
10. 重复导入、错误任务/范围等既有保护继续有效。

## 数据与升级

数据库升级采用幂等 additive migration。

主要新增：

- task lineage 字段；
- task workspace / issue history 的 parent/root/depth 与 target type；
- 处级任务冻结范围支持；
- 分级成果提交 envelope。

升级前仍建议独立备份 V1.0.2 `local_data`。

- 正式业务范围仍为附表2.1～2.14；
- Web Hybrid / Web Center 继续独立实验，不进入桌面 V1.1.0 正式包。
