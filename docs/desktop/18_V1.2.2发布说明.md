# V1.2.2 正式补丁版发布说明

V1.2.2 是调查记录列表布局修复版本。当前为正式候选构建，现场验收及正式发布仍待甲方确认。

## 修复背景与影响范围

小窗口、较低分辨率或较高显示缩放比例下，操作区、筛选区及统计栏占用高度后，底部列表可能仅露出表头。附表2.1～2.14现在通过同一个公共列表组件提供整页纵向滚动；表格最小高度为300px，有剩余高度时弹性扩展，大量记录仍在表格内部滚动。统计文本可换行，避免不必要的横向撑宽。

页面滚动用于访问顶部按钮、筛选条件、统计和表格；表格内部横向滚动用于查看后续字段，内部纵向滚动用于浏览记录。小窗口下请使用页面最右侧纵向滚动条访问下方表格；空列表没有数据行属于正常情况。

## 保持不变的业务行为

不修改附表1、14张工程表定义、数据库结构及迁移规则、工程编号、状态、评价规则、影像同步或导出逻辑。EngineeringAsset / SurveyRecord数据结构、UID及revision/source_revision保持不变；任务协议V3和成果协议2.2保持不变。

## 程序包与兼容性

- `YindaSurveySystem_V1.2.2_Windows_x64.zip`：全新安装或完整程序恢复使用，必须完整解压，不要只复制EXE。
- `YindaSurveySystem_V1.2.1_to_V1.2.2_Update.zip`：仅供现有正式V1.2.1安装升级，其他来源版本会停止。
- ZIP旁的SHA256清单用于核对文件完整性；安全更新程序另校验payload的逐文件清单。

V1.2.2仅修复UI，不发生新数据库迁移，不新增`pre_v1_2_2_upgrade`标记或首次启动备份要求。历史V1.2.0、V1.2.1迁移保护按原逻辑保留，不能将这些历史能力视作本次新增迁移。

## 甲方升级步骤

1. 退出软件，另行留存现有`local_data`备份，核验升级ZIP的SHA256。
2. 将升级ZIP解压到独立文件夹，运行“升级到V1.2.2.bat”，选择现有V1.2.1安装目录。
3. 更新程序校验payload和安装版本、检查运行进程，并在替换程序前完整复制`local_data`到`upgrade_backups/V1.2.1_to_V1.2.2_<时间>/local_data`。
4. 等待成功提示及`UPDATE_COMPLETED.txt`生成，再从原安装目录启动EXE，确认V1.2.2。
5. 检查原项目、调查和影像；在附表2.1、2.2验证页面滚动、表格内部滚动、筛选、双击及正式原表导出。原有记录无需重新导入。

## 回退与备份

程序文件替换失败时，更新程序恢复已移动的旧程序文件；原`local_data`不会被更新器删除或覆盖。更新成功后如需人工回退，先退出软件并另存当前数据，使用已核验的V1.2.1完整包恢复程序文件，再按实际情况恢复升级前的数据备份。不要覆盖升级后新增的数据。安装文件替换前的完整文件级备份与历史数据库迁移保护是不同的机制。

## 验收边界

滚动补丁已完成E盘源码测试和隔离数据界面验证。本轮候选包的构建、真实V1.2.1二进制隔离升级及一致性结果，以候选产物目录随附的`V1.2.2_候选验收报告.json`为准；甲方现场验收尚未完成。本轮不创建正式Tag、不推送、不合并main，也不在生产安装目录执行更新。
