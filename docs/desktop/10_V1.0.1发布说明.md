# V1.0.1 发布说明

## 版本信息

- 产品名称：引大入秦工程现状调查采集系统
- 版本：V1.0.1
- 阶段：正式版
- 补丁收口日期：2026-09-19
- 升级基线：V1.0.0

## 本次补丁范围

V1.0.1 为 V1.0.0 的业务字段补丁版本，不扩展新的调查业务域。

根据甲方对正式附表2签字栏的确认，附表2.1～2.14统一补充以下四项可录入字段：

- 调查人签字；
- 水管所负责人；
- 工程科科长；
- 基层处负责人。

四项当前均允许为空，不作为“录入完成”的强制条件。

“调查人签字”允许多人，系统按用户输入的原始文本保存，不拆分、不排序、不推断姓名边界。例如可录入：

```text
张三、李四、王五
```

## 数据与导出

四项签字属于 `SurveyRecord` 公共字段，而不是14张附表各自的 `record_data_json` 私有字段。

V1.0.1 已完成：

- 新建和编辑调查记录时保存四项签字；
- 草稿、录入完成记录重新打开后正确回填；
- V1.0.0 既有数据库自动增加四个可空字段；
- 既有调查记录升级时不修改原有调查内容；
- 正式原表 Excel 写入四项签字；
- 详细汇总 Excel 增加四项签字列；
- 多人调查人文本完整保留。

## 任务与成果交换兼容性

`.ydtask` 调查任务包协议及任务分发、任务接收、冻结范围、来源追踪机制本次不变。

`.ydresult` 调查成果包因新增调查记录字段升级为 result schema `2.1`：

| 成果包 | V1.0.0 接收端 | V1.0.1 接收端 |
| --- | --- | --- |
| result schema 2.0 | 支持 | 支持 |
| result schema 2.1 | 不支持 | 支持 |

因此：

- V1.0.0 已生成的正式 2.0 成果包可继续由 V1.0.1 总库接收；
- V1.0.1 新生成的 2.1 成果包包含完整签字字段；
- 不允许用 V1.0.0 接收端导入 2.1 成果包，以避免旧版本静默丢失签字字段。

任务来源仍使用：

```text
source_task_uid
+
source_management_scope_uid
```

原有 issued-task / issued-scope 冻结快照校验、导入前备份、事务化导入和重复导入保护保持不变。

## 升级与数据安全

V1.0.1 启动既有 V1.0.0 数据库时，通过幂等 schema migration 为 `survey_records` 增加四个可空签字字段。

升级原则：

- 不删除 V1.0.0 既有字段；
- 不改写已有调查记录；
- 新增签字字段初始为空；
- migration 可重复执行；
- 升级后可继续编辑旧记录并补录签字。

正式升级前仍建议保留 V1.0.0 `local_data` 的独立备份。
