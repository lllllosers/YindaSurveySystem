# V1.2.1 生产反馈修复

- 桩号输入使用 Decimal / ROUND_HALF_UP 统一到 0.001 m，允许起点等于终点；历史桩号只在展示与正式导出时规范化。
- 工程台账、数据查询默认按渠系、起点数值、终点数值排列，支持点击表头排序。
- 真实来源任务在本机接收工作区及冻结范围内的记录仍可编辑；下级导入成果只读，保存、完成、删除和影像修改在业务层同时保护。
- 新增成果接收明细，区分 new / updated / existing / stale。接收历史可直接打开数据查询查看本次新增与更新，重复已有成果不刷新变化时间。
- 接受的非 stale 记录按合法成果包同步当前影像集合；同 UID 内容变化可同步，跨记录身份冲突仍阻断。文件通过 staging、原子替换及失败恢复处理；本机影像变化递增父 revision。
- 调查主窗口及相关影像、工程详情窗口根据屏幕可用逻辑尺寸适配，保留表单及表格滚动。

## 安全升级

支持 V1.2.0 → V1.2.1。升级器替换程序前完整备份 local_data；首次启动在 schema 初始化前创建 pre_v1_2_1_upgrade SQLite 备份，失败停止。原 pre_v1_2_0_upgrade 保护保留，升级备份不受常规备份保留数量清理。

仅新增 survey_result_import_record_changes 及索引；不回填历史接收明细，不批量修改正式业务表，不重建 UID、不重置 revision，不要求用户重新导入或人工迁移。.ydtask V3 / .ydresult 2.2 保持。

本轮不涉及 Web 成果导入修复、新审核状态机或退回流程。发现下级成果问题，由原调查单位修正后重新提交。
